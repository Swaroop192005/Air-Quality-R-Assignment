# Air-Quality-R-Assignment
# Air Quality Data Cleaning using R

## Description
This project performs data cleaning on the Beijing Multi-Site Air Quality Dataset.

## Tasks Performed
- Import and inspect dataset
- Handle NA, NULL and NaN
- Generate missing value summary
- Clean numerical variables using median
- Clean categorical variable using mode
- Error handling using tryCatch()
- Generate comparison table
- Create missing value visualization
- Export cleaned dataset
